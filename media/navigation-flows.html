lisp-over-linux · code browser

How you move through the code

Two motions, and one rule. You drill downward to open things (the accordion), and the browser previews sideways — read-only — to the right. Anything that is our source you can edit where you stand; a builtin you can only read.

The vocabulary

▼

drill

Enter / click a row. Opens the target below, stacking the accordion. The current pane collapses to a breadcrumb.

▶

preview

Selecting a row shows its target to the right, live and read-only — except a matrix preview, whose cells are live (see below).

↗

new tab

Super-Space (Spotter) or Super-Enter opens the target in a fresh trail instead of drilling in place.

✎

editable end

A drilled pane over our source is editable — C-c C-c recompiles it live. Builtins are read-only.

Path 2 — the dispatch matrix → the effective method → a layer's code

A generic function that dispatches on two arguments has a real 2-D dispatch matrix. Its preview is live: click a cell and you land straight on that class-pair's effective method — no need to open the matrix first. The effective method is itself a browsable list of the methods that run, in order, each drilling to its own editable source.
