The agent indicator
— who else is in the room

Once the environment can act on its own, you must always be able to see whether it may, and what it is allowed to touch. This is the only thing in the project that earns permanent chrome. Three surfaces carry it — the tab strip, the presence light, and the REPL prompt — using one grammar and no new palette entries.

1

One grammar, two channels

Two orthogonal dials (§8.9), so two orthogonal visual channels. Shape carries initiative — absent, hollow, filled. Colour carries authority — and every colour already means this in the existing semantic palette, so nothing new has to be learned or invented.

The tab strip

True draw-tabs metrics: a 20 px bar, 8 px gutter, 6 px between tabs, a 2 px kind stripe on top of each, " N · " dim then the title, × on the active tab, + for a new Workspace, the app name right-aligned. The dot goes in the leading space of the number — 5 px of already-blank pixels at x+2. Nothing moves; nothing is displaced.

The quiet rule. A dot on every tab, always, would be noise — and this environment hides its cheatsheet behind Super-? precisely to avoid that. So a tab shows a dot only when it deviates from the global default or is working. The global light below is what tells you the agent exists at all.

3

The presence light

The right end of the tab strip already holds the app name — the “this is the environment” slot. That is where the global state belongs, and the project already owns the perfect mark for it. Not the 256 × 150 sprite: at that size it would swallow the bar. A new 16 × 16 glyph, ~32 bytes, hand-authored the same way the font blob was.

:off — #2E343D
:reacting — #6B727D
:interacting / :ask — #FF9F43
:interacting / :allow — #FF6B6B
7× · the eyes are holes, so the glyph reads at 16 px without anti-aliasing

Same grammar as the dot, one level up: the alien’s colour is the authority you have granted, so a glance from across the room tells you whether this machine can change itself right now. Note it deliberately does not use the green of :method/:generic-function — the agent is not a kind of definition, and stealing a semantic colour would be a lie.

4

The REPL prompt

Every Lisp shows *package* in the prompt; this environment should show *agent-initiative* the same way. One leading mark, then the prompt — so the grammar survives on a surface with no pixels at all, including over the network REPL.

Hard constraint from ansi.lisp: fbcon honours only the 16 ANSI colours — no 38;5;n, no truecolor. So the palette maps to SGR codes rather than hexes, and the mapping keeps the meanings intact.

Open questions the mock does not settle: whether the alien should also carry working (a blink) or leave that to the tab dots alone; whether :off should hide the glyph entirely rather than grey it (hiding is honest, greying tells you the capability exists and is switched off — probably the latter); and the exact 16 × 16 pixels, which are a starting point, not a decision.
