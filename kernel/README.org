The kernel source tree isn't in this repo; the build reaches it through the
gitignored =./linux= symlink ([[file:../README.org][../README.org]]). That tree is unmodified upstream
Linux plus one file that matters, the =.config=. This directory keeps a tracked
*copy* of it so the kernel side of the project can't be lost.

- *=config-7.2.5=* — verbatim snapshot of the live =linux/.config=; the current one.
- *=config-7.1.3=* — Linux 7.1.3 (kernel tag #23; that series is EOL).

* This is a snapshot, not the live file

The live =.config= (=../linux/.config=) is the truth. After any kernel config
change, refresh the snapshot in the same commit (from the project root):

#+begin_src sh
  cp linux/.config kernel/config-7.2.5
#+end_src

* Rebuilding the kernel from scratch

#+begin_src sh
  ./deps.sh kernel 7.2.5       # downloads the tree, symlinks ./linux, and
                               # copies config-7.2.5 in as .config + olddefconfig
  ./build.sh --kernel
#+end_src

When bumping to a new kernel version, snapshot its config as a new
=config-<version>= file and commit it with the change.
