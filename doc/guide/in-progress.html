How to add a section when one of these lands

  1. Write the page as a copy of an existing one. Keep the empty <!-- nav:begin --><!-- nav:end --> markers, then add one line for it to +pages+ in doc/guide/regen.lisp.
  2. Cite code only as <a class="ref" data-ref="FILE#NAME"></a> (or FILE#NAME@SPECIALIZER for a method, FILE#"literal text" for C, shell or org). Never type a line number by hand.
  3. New Lisp files: add each one to a layer in +layers+ in the same script. The script warns about a module with no layer.
  4. Run sbcl --script doc/guide/regen.lisp until it says 0 unresolved; 0 errors, then ./check-links.sh --quiet.
  5. If the subsystem deserves a stop in the in-image tour, add one entry to *tour-stops* in initramfs/tour.lisp and to tour.org, then run check-tour.lisp.
  6. Move its row above from "in progress" to merged, or delete it.
